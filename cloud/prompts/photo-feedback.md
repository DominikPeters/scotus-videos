# Revise an advocate image after owner feedback

Read input/request.json and input/advocate.json. The owner has asked to find a
different image, recrop the same source, or switch to a synthetic alternative.
Use their optional hint to guide this task. Preserve the verified advocate's
identity; disambiguate with firm/agency, location, docket and profile sources.
Rejected images and reasons are supplied as context. Do not return the same
image for a request to find a different one. Prefer a suitable, large portrait.

For synthetic alternatives, choose initials or a verified firm/agency logo.
Do not fabricate a logo, an advocate's face, or an image URL. For initials, supply
one to four letters; the application draws a simple square graphic. If the hint
requests a logo, search for the actual logo and record its source. Choose a directly
downloadable PNG, JPEG or WebP source for logos. Any uncertainty belongs in the
private note. Every replacement requires fresh owner approval.
